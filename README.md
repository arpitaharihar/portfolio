# Arpita Harihar - Data Analytics Portfolio (React.js)

A portfolio website for **Arpita Harihar** built with **React 19** and **Vite**, featuring an interactive dashboard panel, full project showcase with exact GitHub repository links, dark/light theme support, categorized tech competencies, and a 100% reliable downloadable resume.

---

## 🚀 Features

- **Exact Project Links Included**:
  1. **Customer Behavior Analysis**: [`https://github.com/arpitaharihar/Customer-Behavior-Analysis`](https://github.com/arpitaharihar/Customer-Behavior-Analysis)
  2. **NGO Volunteer Analytics Dashboard**: [`https://github.com/arpitaharihar/NGO-Volunteer-Dashboard`](https://github.com/arpitaharihar/NGO-Volunteer-Dashboard)
  3. **FNP Sales Analysis**: [`https://github.com/arpitaharihar/FNP-Sales-Analysis`](https://github.com/arpitaharihar/FNP-Sales-Analysis)
  4. **Ecommerce Sales Analysis**: [`https://github.com/arpitaharihar/Ecommerce-Sales-Analysis`](https://github.com/arpitaharihar/Ecommerce-Sales-Analysis)
  5. **Netflix Movie Data Analysis**: [`https://github.com/arpitaharihar/Netflix-Movie-Data-Analysis`](https://github.com/arpitaharihar/Netflix-Movie-Data-Analysis)
- **Categorized Skills & Tooling**:
  - **Programming & Analysis**: Python (Pandas, NumPy, Matplotlib, Seaborn), SQL (Joins, CTEs, Window Functions, Aggregations), C++, HTML, CSS
  - **Databases & Warehousing**: MySQL, PostgreSQL, Supabase, Relational Modeling
  - **Analytics & Visualization**: Power BI, Tableau, Excel (Pivot Tables, VLOOKUP/XLOOKUP, Power Query), DAX, Matplotlib, Seaborn
  - **Data Processes**: ETL/ELT, Data Cleaning, Data Modeling, KPI Reporting, Dashboard Development, Data Validation
  - **Tools & Workflow**: Jupyter Notebook, Git, GitHub, VS Code, PyCharm, IntelliJ IDEA, Apache NetBeans
- **Interactive Project Filtering**: Filter projects seamlessly by category (*All*, *Power BI*, *Python & SQL*, *Excel*).
- **Guaranteed Downloadable Resume**:
  - Embedded Base64 binary fallback & direct public link (`/Arpita_Harihar_Resume.pdf`).
  - Download buttons in Top Navigation, Hero section, and Contact card.
  - One-click copy for email address.
- **Hero Dashboard Preview**: Interactive KPI cards showing ₹95,468 revenue, 34 orders, and order metrics from the FNP Excel analysis.
- **Dark / Light Theme Toggle**: Seamless switching with local storage persistence and system preference detection.
- **Typography & Styling**: Clean IBM Plex Sans and Bricolage Grotesque typography with responsive layouts.

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
